# tennis-courts_info

「そうだ！テニスをやろう！」のご案内サイト（GitHub Pages）。

- `index.html` ご案内トップ（出欠・開催、参加費、補足案内）
- `courts.html` 主要コート情報（料金・キャンセル期限）
- `style.css` 共通スタイル

JavaScriptは使っていません。両ページに `noindex, nofollow` を設定していますが、これは検索結果に出にくくするだけで、アクセス制限ではありません。個人情報・秘密情報は掲載しないでください。

コート情報のページ末尾の基準日（「コート情報：○年○月時点」）は、料金・キャンセル期限を確認して更新したときに手動で書き換えます。
